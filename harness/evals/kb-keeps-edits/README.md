# kb-keeps-edits

Proves: the knowledge-base scaffold replaces a profile, analysis.md or status-matrix.md only while it is exactly what the scaffold wrote (its frontmatter carries the hash), so a section a person adds survives a re-run; a document an older scaffold wrote (no hash) is never replaced by install or intake, and acp kb scaffold replaces it only when it is what the scaffold writes today apart from its date and tree hash.
