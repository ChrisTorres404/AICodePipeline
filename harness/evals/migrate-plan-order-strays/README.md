# migrate-plan-order-strays

Proves: acp migrate plan files each order's stray material beside the repository into that order's folder, at any depth and in any folder: a note (.md) as <ID>-NOTES|HANDOFF|DRAFT-<n>.md, numbered without case after what the folder holds and what a copy outside will carry in; anything else under the order's artifacts/ with its path relative to the project, so no two items share a place; an exact copy of the order's own document dropped (never an empty file). Every item is planned after every order copy, and placeholders, folders and files, last. It asks, never guesses, when an item may be private (a key file, or a line sanitize's rules match, in any of its files, a file not read never hiding a later one, nor a binary one a file asked about; else a file too large or binary to read; files are read in bounded pieces, pictures not at all), when its place is taken, for a placeholder number (adopt as the next free number), an order the repository lacks, two orders named, and a bare number that is an order's, suggesting the private folder, and saying why, whenever something private may be inside; the folder question is asked whenever the private folder is offered. A private or knowledge-base folder is never broken apart, a folder of numbered frames is a sequence, and a residue file holding a secret, or a text file over 50 MB that could not be read for one, is asked about (a binary one stays residue). A folder named for an order is a copy only when it holds the order's metadata or documents; one holding an order copy or a repository is looked into. Every filed or asked entry carries its digest.
