# migrate-plan

Proves: acp migrate plan, on a synthetic messy project (a repository inside the project folder; work orders beside it that are new, differing, identical, contained, of the same size with other bytes, unreadable in part, holding a named pipe, a nested repository or a .git with no HEAD, differing only in the exec bit or an empty folder, deep in the tree, or a repository of their own; second ACP copies, one holding unique work; a repository nested in the work; loose documents; knowledge-base snapshots; logs; private files; an unknown; stale branches; no remote), writes only .acp-migration/ with every entry classified and every decision a numbered question, never calls a copy identical when it is not, records a digest of every copy it drops, leaves every other byte, mode and time unchanged, runs no hook or filter driver from the project or its submodules (a repository with submodules is asked about, never looked into) and ignores the caller's GIT_* settings, refuses pipeline folders reached through a link or named with .., refuses with one line whatever it cannot read or write, needs git 2.15, never writes through a link, refuses to overwrite a plan, and refuses an ambiguous, deeper or pipeline-less repository and bad arguments with their line.
