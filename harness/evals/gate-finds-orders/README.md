# gate-finds-orders

Proves: the evidence gate finds the closed orders in the configured folders itself, so under block an order git status does not list (inside a nested repository or a submodule, in an ignored folder, behind a skip-worktree or assume-unchanged mark or a clean filter, through a linked folder, in a folder pipeline.config.sh names) blocks with its reason, while an old record whose repository last committed exactly the bytes on disk stays as it is.
